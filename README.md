# Snippets

## Description

A quick capture app for writing ideas. This app will give users the ability to quickly open, and log writing ideas while away from their notebooks or computer. This project is being created so my sister can keep track of, and sort through, her ideas as she gets them throughout the day.

The app will have a username and login, and buttons to create projects, or add snippets of information to the projects. It also allows for standalone ideas that don't necessarily pair with any current projects. It will also have a to do section for things that a user might want to research later, or maybe a reminder to change something, or look into something related to their projects.

Users will have the ability to select from several categories including character, scene, worldbuilding, idea, plotpoint, outline, arc, backstory, rule, dialogue
